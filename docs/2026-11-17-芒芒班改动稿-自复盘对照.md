```markdown
## 〇、自复盘影子运行（先做 · 做完并校验通过之后才能读课件）

并行期任务（2026-11-17 Doctor 立 · 至 Doctor 提出切换为止）：不看课件，只凭独立数据写一份当日自复盘记录，再与课件信号对照。这一节的产出不进日报、不进 recap.db。

**次序铁律**：本节第 1 至 3 步全部完成之前，不打开任何课件、不查 recap.db 里当日入库的内容、不读九儿当日的入库日志。次序反了就在 records.json 里写 `"blind": false` 并说明原因。

0. 追加挂载 `~/Documents/Codex/Project Mirror/烛照九阴日报`。挂好后导出：
   `export ZZJY_VV_TOOL="<该挂载点>/skills/anchor-follow/scripts/build_inputs.py"`
   （`ZZJY_DATABASE_ROOT` 沿用本班前置里已导出的值。）
1. 出输入包：`cd <烛照九阴挂载点> && python3 tools/self_recap_inputs.py`。
   它只读行情库和资讯看板的冻结快照，不读 recap.db。返回 `status: failed` 就停下，把原因记进审核日志的「自复盘」一段，本节到此为止，接着做后面的审查；不重试，不用别的数据顶替。
2. 写记录：读 `docs/自复盘-记录写法.md`，按其中的格式写 `data/self_recap/<交易日>/records.json`。分析步骤照 `<Codex 挂载点>/skills/anchor-follow/SKILL.md`，每类锚的读法照《锚的大类逻辑卡》。只用输入包里的数据和你当场能核到的原始来源；取不到的写缺口。
3. 校验：`python3 tools/self_recap_validate.py data/self_recap/<交易日>/records.json`。不通过就按报错改，改到通过为止；改不了的在审核日志里写明哪一条、为什么。
4. 做完后面的「一、六项审查」之后，回来跑对照：`python3 tools/self_recap_compare.py --date <交易日>`。再读课件当日的行业信号和你自己的记录，把两边方向相反的主线数填进 `data/self_recap/compare.csv` 该日一行的 `opposite`，理由写进 `opposite_note`；没有就填 0。
5. 审核日志加一段「自复盘」：输入包是否成功、记录几条、校验是否通过、对照的三个数（重合、课件独有、自复盘独有）、方向相反几条、是否盲写。

边界：本节不写 recap.db，不改课件入库内容，不改日报。当日没有课件入库时照做第 0 至 3 步，第 4 步的对照会记「当日无课件入库」。
```

## 交易日的取法

`self_recap_inputs.py` 不带参数时取行情库 `daily_market` 最新一日。本班每日 09:30（太平洋时间）跑，行情库的日更在它之前；若行情库当日没更新，输入包的交易日会是上一个交易日，此时不要重复写同一天的记录，在日志里记一句即可。行情库的更新时间与本班的先后没有实测。
